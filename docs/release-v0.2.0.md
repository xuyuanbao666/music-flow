# MusicFlow v0.2.0

基础重构版（Web）。本版本改善本地音乐播放体验，不是 Windows、Android 或 iOS 原生安装包。

- 本地音频通过 IndexedDB 持久化，刷新后可重新播放；旧版临时链接须重新导入。
- JWT 验证与歌单所有权检查、事务保护。
- 修正音量重复增益、播放队列、切歌及错误提示。
- 支持触屏/键盘的进度和音量滑块，优化移动端播放栏、歌词和收藏。
- 在线服务需自行配置合法音源；云同步和原生客户端尚未完成。

## 使用方法
解压 musicflow-v0.2.0-web.zip，将文件部署到 HTTPS 静态网站的 /music-flow/ 路径；不能直接双击 index.html。使用本地模式无需账号。开发方式见 README。

SHA256SUMS.txt 用于核对下载文件。发行由主分支的构建、安全测试和 Chromium 浏览器测试通过后触发；未进行原生设备测试或完整云端集成测试。
